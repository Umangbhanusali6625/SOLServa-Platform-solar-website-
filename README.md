# SOLSERVA Website

Official responsive website for SOLServa - Solar Monitoring & Clean Energy Solutions.

## Pages

- `index.html` - Home page
- `about.html` - About us
- `services.html` - Services
- `solutions.html` - Solar solutions
- `epc-partners.html` - EPC partner program
- `how-it-works.html` - How the platform works
- `calculator.html` - Solar savings calculator
- `resources.html` - Resources & FAQs
- `contact.html` - Contact us

## Technologies Used

- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)

## How to Run

Open `index.html` in any web browser, or preview using a local server (such as VS Code Live Server).
