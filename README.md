## 🌟 Overview

SOLServa is an intelligent solar telemetry, plant monitoring, and O&M coordination platform built for Solar EPC contractors, Commercial & Industrial (C&I) plant operators, and residential rooftop system owners across Gujarat and India.

## 🚀 Key Features

- **Modern Architecture**: Multi-page website with clean modular CSS architecture (`base.css`, `layout.css`, `components.css`, `pages.css`, `style.css`).
- **Interactive Financial Calculator**: Real-time solar ROI, savings, payback period, and clean energy generation estimator.
- **Inverter Compatibility Engine**: Searchable and filterable database supporting over 30+ inverter brands and IoT telemetry hardware.
- **Comprehensive O&M Services**: Preventative maintenance, drone thermography scheduling, module washing cycles, and ticket dispatch workflows.
- **Search Engine Optimization (SEO)**: LocalBusiness, Service, and FAQPage Schema.org structured data, dynamic OpenGraph meta tags, `sitemap.xml`, and `robots.txt`.
- **Responsive & Accessible Design**: Zero horizontal overflow, optimized touch targets, accessible modal dialogues, and responsive mobile navigation.
